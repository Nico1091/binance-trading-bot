ℹ️ ¿Cómo funciona este bot?

Este dashboard se conecta al backend Node.js, el cual usa la API de Binance Live. El backend obtiene balances, órdenes y precios en tiempo real, y ejecuta estrategias automáticas de trading.

El bot analiza velas de 1 minuto (BTC/USDT) aplicando indicadores como RSI, medias móviles y patrones de velas. Cuando se cumplen condiciones específicas, genera órdenes de compra o venta automáticamente.

En la sección "Logs del bot" verás en tiempo real qué estrategia activó la operación y con qué parámetros. Puedes probar también crear órdenes manuales usando el formulario.
